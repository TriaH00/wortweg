# Wortweg · impara il tedesco

App web installabile (PWA) per imparare il tedesco: lettura e ascolto con parole cliccabili, le 1000 parole più frequenti, ripasso a intervalli, shadowing, pronuncia, dettato, numeri, un manuale di grammatica in italiano e dialoghi guidati.

- Nessun account, nessun abbonamento: i progressi restano nel browser (esportabili come file dalle impostazioni).
- Funziona offline dopo la prima apertura; dalle impostazioni puoi scaricare tutto l'audio.
- Correzione gratuita con [LanguageTool](https://languagetool.org), traduzione con [MyMemory](https://mymemory.translated.net), pronuncia con il riconoscimento vocale del browser.
- Voce: Thorsten (Piper, CC0). Ogni clip è stata verificata con un riconoscitore vocale.

Per installarla: apri il sito, poi «Installa app» (Chrome/Edge) o «Condividi › Aggiungi alla schermata Home» (Safari su iPhone).
